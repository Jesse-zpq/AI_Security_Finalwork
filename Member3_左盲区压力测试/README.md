# Member 3 · 左盲区压力测试与停车后备

**T1 只移除真实左后车。** 当左后车存在时，常规策略 A 左移，在 2.00 s 与它碰撞。移除左后车后，A 仍然左移，在 25 s 观察期内无碰撞。策略 C 在两组中均取消左移。对有车的 P2，这次否决避开了一次实际碰撞；对无车的 T1，它放弃了一次实际完成的变道机会。结论针对本组有限时域、脚本化交通和给定盲区边界。

可直接合入总汇报的[第 4–5 页 PowerPoint](第4-5页_左盲区与停车后备.pptx)含两张可编辑表和约 95 秒的分段讲者备注。数据基于仓库版本 `c69fc8a` 的正式 CARLA 1.0 日志。本目录完成日志复算、六条独立二维重跑和接管截止复核。

## 配对设计

方案 §4.2 的本项新增运行是 T1-A、T1-B、T1-C；各自与同策略 P2 配对。N1-A 只用于解释观测故障。盲区目标观测在 0 s、跨线前丢失，并持续到轨迹终点。六条都采用左变道意图，驾驶员无就绪事件。初始观测均为前车 F、右后车 R、中道后车 Bk。P2 的真实状态里另有 L；T1 的覆盖项为 `{"L": null}`。两组共享 C 的左车先验，包括相对初始位置 [−30, −15] m、速度 [32, 34] m/s，横向为左道中心 ±0.3 m。

| 复现实验的参数 | 设定 |
|---|---|
| 道路与坐标 | 直线三车道及右路肩；车道宽 3.6 m，路肩宽 3.0 m；中道中心为 y = 0，向左为正 |
| 车辆中心初值（纵向位置 m / 速度 m/s） | 中道自车 E 0 / 25，前车 F +50 / 20，后车 Bk −60 / 27；右道 R −50 / 27；仅 P2 有左道 L −20 / 33 |
| 车身与评分 | 正式自车约 4.694 × 2.088 m，逐帧使用日志车身尺寸和航向；规划纵、横裕度分别为 2.0、0.2 m |
| 时间与控制 | 物理步长 0.05 s，决策步长 0.10 s；变道单段 3.5 s；B 目标加速度 −4 m/s²；观察上限 25 s |
| 交通与终点 | Bk 脚本在 2 s 后以 −5 m/s² 制动至零；停车速度阈值 0.2 m/s，稳定确认 0.5 s 加停后观察 3 s |

## 动作矩阵与截止复核

| 候选动作 | 放行条件 | T1-C 的检查结论 |
|---|---|---|
| 普通左变道 | 对左侧和左后交通有可信观测，轨迹占用通过检查 | 0 s 以 `left_observation_unknown` 否决。A 在 P2/T1 均只用可见目标检查，得到相同的 +25.825 m 候选分数并放行 |
| 中道短时跟驰 | 等待过程满足净空要求，每个待检查时刻仍有能完成的停车后备 | 0 s 请求接管，持续按 0.10 s 检查；4.70 s 达到截止 |
| 中道受控停车 | 制动过程和停后时段通过道路、前后目标与未知区检查 | 0 s 裕度 +1.156 m；4.70 s 裕度 +1.312 m，实际启动 |
| 两段向右靠边停车 | 从中道跨入右道、再入路肩、制动和停后均通过检查 | 0 s 裕度 +1.012 m；4.70 s 判断这条候选将在场景时刻 10.10 s 受 R 限制，否决 |

**左移冲突核对。** N1-A 在起点可见 L，预测 1.70 s 首次违反裕度（首个否决分数约 −0.350 m）。P2-A 在 2.00 s 的碰撞由 CARLA 传感器记录。课堂算例用 20 ÷ (33 − 25) = 2.50 s 描述匀速纵向中心齐平。三者分别是规划判据、物理接触和简化运动学量。规划裕度扣除了纵横安全余量，与评分表里的车身净空有不同的定义。可检查[首帧和后备启动帧](results/decision_evidence.json)。

**给 Member 4 的交叉复核。** 在 P2-C 和 T1-C 的每个决策帧，重建当时观测与后车加速度，枚举可等待时长，同时检查等待轨迹和未来停车候选。可行上限扣除 0.30 s 启动余量，并与之前的截止时刻取较早者。两条轨迹起点均得到 5.00 − 0.30 = 4.70 s。每条从 0 至 4.70 s 共 48 个决策点都有至少一个立即可启动的停车候选，逐行复算截止均与日志相符。见[全部 96 个决策点](results/deadline_audit.csv)。

## 二维重跑与复现

用仓库同一工况清单、策略与评分器，通过 `ModelWorld` 新生成六条轨迹。[二维结果](results/model_pairs.csv)中 P2-A 于 1.90 s 碰撞，T1-A 运行到 25 s；B 两条均在 9.75 s 完成中道停车观察，C 两条均在 4.50 s 启动后备、13.50 s 完成观察。两个后端的结论在这些配对上一致，碰撞判定和运动模型带来了具体时间差异。

在仓库根目录运行（Python 3.10+，标准库）。脚本默认重新生成本目录的四个结果文件；`--output` 可指定另一目录。正式日志核验使用仓库的原始批次校验器。

```powershell
python -B ".\Member3_左盲区压力测试\run_t1.py"
python -B ".\Member2_主对照\work\verify_formal_batch.py" ".\CARLA_Member3-4-5_Handoff\CARLA_repro_handoff\CARLA_formal_results"
```

复算入口调用 [replay.reproduce](../CARLA_Member3-4-5_Handoff/CARLA_repro_handoff/replay.py) 核对正式帧、动作和评分。工况来自 [make_runs](../CARLA_Member3-4-5_Handoff/CARLA_repro_handoff/core/carla_preflight.py)，候选检查来自 [check_plan、Policy.stop_options](../CARLA_Member3-4-5_Handoff/CARLA_repro_handoff/core/carla_pilot.py)，指标来自 [score_run](../CARLA_Member3-4-5_Handoff/CARLA_repro_handoff/core/carla_metrics.py)。要重新生成物理轨迹，可使用交接包的 [CARLA 实跑说明](../CARLA_Member3-4-5_Handoff/CARLA_repro_handoff/README_Usage.md)。

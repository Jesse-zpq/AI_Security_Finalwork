# Member 5 · 基线与主对照

**12 条主对照把同一故障拆成「意图 × 接管 × 策略」三个因素。** A 的两次碰撞与接管条件无关：它不请求移交，只按可见目标做常规避碰。B 的结局与意图无关：0 s 制动、9.80 s 停稳，四种条件完全一致。**只有 C 随接管改变**：及时分支在 2.50 s 完成稳定移交，无人分支等到 4.70 s 截止才启动中道停车。

可直接合入总汇报的[第 7–8 页 PowerPoint](第7-8页_基线与主对照.pptx)含一张可编辑的 4×3 对照表和一张四联主结果图，约 100 秒的分段讲者备注写在备注栏。数据基于仓库既有 CARLA 1.0 正式日志（`CARLA_formal_results`），本目录完成 14 条日志的指标重算、配对表、绘图和一项交叉复核。

## 主对照设计

按方案 §4.2，基础 23 次里本项占 14 条：2 条正常观测参照（N1-A、N2-A）和 12 条主对照（P1–P4 × A/B/C）。成对关系是 P1↔P2、P3↔P4，两对共享同一道路、初始状态与故障，只改接管条件。参照 N1-A 与 P2-A 配对、N2-A 与 P4-A 配对，交通与意图相同，只把观测换回正常。

| 条件 | 意图 | 接管 | 配对 |
|---|---|---|---|
| P1-A/B/C | 左变道 | 2.00 s 就绪 | P2 同策略 |
| P2-A/B/C | 左变道 | 无 | P1 同策略 |
| P3-A/B/C | 跟驰 | 2.00 s 就绪 | P4 同策略 |
| P4-A/B/C | 跟驰 | 无 | P3 同策略 |
| N1-A / N2-A | 左变道 / 跟驰 | 正常观测 | P2-A / P4-A |

共同参数沿用公共交接包：车道宽 3.6 m、路肩 3.0 m；自车 0 m/25 m/s，前车 +50 m/20 m/s，左车 −20 m/33 m/s，右后车 −50 m/27 m/s，中道后车 −60 m/27 m/s 并在 2 s 后以 −5 m/s² 制动；物理步长 0.05 s、决策步长 0.10 s；规划裕度纵 2.0 m、横 0.2 m；观察上限 25 s。

## 12 条主对照的结果

| 条件 | A 常规规划 | B 立即停车 | C 动作筛选 |
|---|---|---|---|
| P1 左变道 · 及时 | 2.00 s 与 L 碰撞 | 0 s 制动，9.80 s 停稳 | 2.50 s 完成移交 |
| P2 左变道 · 无人 | 2.00 s 与 L 碰撞 | 0 s 制动，9.80 s 停稳 | 4.70 s 启动，13.70 s 停稳 |
| P3 跟驰 · 及时 | 跟驰 25 s，无碰撞 | 0 s 制动，9.80 s 停稳 | 2.50 s 完成移交 |
| P4 跟驰 · 无人 | 跟驰 25 s，无碰撞 | 0 s 制动，9.80 s 停稳 | 4.70 s 启动，13.70 s 停稳 |

**两条参照。** N1-A 在起点可见左车，预测 1.70 s 会违反裕度，于是拒绝左变道，25 s 内无碰撞；N2-A 没有决策事件。两条参照的轨迹与 P4-A 数值重合（前 2 s 最小前向净空 35.9 m，25 s 时 23.1 m）。也就是说，故障只改变了左变道分支：正常观测下 A 自己会否决，故障下它只剩前车、右后车、中道后车三项观测，于是放行。

**接管事件没有进入 A、B 的动作逻辑。** P1-A、P3-A 记录了 2.00 s 的 `driver_ready`，但 A 不请求移交；P1-B、P3-B 同样在 2.00 s 就绪，B 仍在 0 s 制动。只有 C 的 `takeover_requested`、`scripted_handover`、`fallback_started` 出现在时间线上，所以 12 条里只有 C 的终点随接管条件变化。

**四条 C 的截止都等于 4.70 s。** 参考交通下等待上限 5.00 s 减去 0.30 s 启动裕度，意图和接管都不改变这一数值；截止提前的情形要由压力条件制造，见 6 号的 T3-C（2.60 s）。

## 主结果图

[四联图](results/main_contrast.png)取左变道意图、无人接管（P2）同一交通下的三条轨迹：

- **a 终点**：A 停在 50 m（碰撞点），B 停在 78 m，C 停在 169 m。
- **b 速度**：B 在 0 s 制动、6.30 s 停稳；C 在 4.70 s 才制动、10.20 s 停稳；虚线是同一交通下的跟驰分支 P4-A。
- **c 横向**：只有 A 向左移动，2.00 s 越过车道线；B、C 全程保持中道。
- **d 后向净空**：共同前 2 s 的最小后向净空，C 保留 50.9 m，B 只剩 43.0 m，差 7.9 m。

四联图的读法是「B 用 7.9 m 后向余量换来提前 4.70 s 制动」。这不是说 B 更差：在 T3 把后车初始位置压到 −20 m 后，B 的立即制动会在 2.35 s 与后车碰撞，那正是 C 保留余量的价值所在。

## 交叉复核（对 6 号压力条件）

方案 §5 要求 5 号独立复跑 6 号的一个压力条件并核对评分口径。6 号产物到位前，先用公共日志对 **T3-B**（后车 −20 m、立即制动基线）做同一复核，结论：

| 核对项 | 结果 |
|---|---|
| 原策略重放 | 事件、碰撞、帧与评分与日志逐项一致 |
| 前 2 s 后向净空 | 日志 3.035 m，独立重算 3.034735 m |
| 前 2 s 前向净空 | 日志 42.394 m，独立重算 42.394138 m |
| 终点 | 2.35 s 与 Bk 碰撞（`carla_sensor`） |

`cross_check.py` 不调用评分器算净空，而是自己按投影口径从帧里重算一遍，用来确认「前 2 s 窗口、车身航向、横向 0.2 m 门限、带符号间距」这些口径与表里的数字对得上。6 号的新目录可用 `--log-root` 与 `--cases` 直接指向。

## 复现

在仓库根目录运行（Python 3.10+，绘图另需 Matplotlib）。脚本读取保留的正式日志，不重复仿真。

```powershell
python -B ".\Member5_基线与主对照\run_m5.py"
python -B ".\Member5_基线与主对照\cross_check.py"
```

`run_m5.py` 先核对清单、`summary.json`、事件和评分重算，任一不符即中止，然后写 `results/` 下的配对表、结果图与核对记录。`--output` 可写到另一目录，`--log-root` 可换日志根目录。
